# @superassistant/platform

Platform web app: React + Vite + TypeScript + [TanStack Router](https://tanstack.com/router) (file-based) + [TanStack Query](https://tanstack.com/query).

## Structure

- `src/routes/` — file-based routes (root layout in `__root.tsx`); route files export only `Route`
- `src/components/` — route components
- `src/routeTree.gen.ts` — generated by the router Vite plugin; do not edit
- `src/main.tsx` — `QueryClientProvider` + `RouterProvider`; router context exposes `queryClient` for type-safe `useQuery` in loaders

## Scripts

```sh
pnpm --filter @superassistant/platform dev      # dev server
pnpm --filter @superassistant/platform build    # tsc -b && vite build
pnpm --filter @superassistant/platform preview  # preview production build
```

Routing and query devtools are enabled in development.
